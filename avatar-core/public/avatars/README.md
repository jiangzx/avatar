# Avatar model assets

The WebView avatar catalog reserves these relative filenames:

- `avatar.glb` - the existing default model
- `cute-girl.glb` - 可爱小女孩
- `cute-boy.glb` - 可爱小男孩
- `young-woman.glb` - 青年美女
- `young-man.glb` - 青年俊男

Each model must be a licensed GLB compatible with TalkingHead 1.7.0 and must
be reviewed on the target phone for framing, materials, facial blendshapes, and
animation quality before it is accepted as product art.

This checkout currently contains only the locally ignored `avatar.glb` supplied
outside Git. The four new GLBs are external inputs and are not claimed to exist
until their provenance and visual acceptance are recorded. Missing files use the
existing model at runtime, so the selection flow remains usable while those
assets are pending.
