# 虚拟形象资源外包交付说明

> 面向：外包 / 美术制作方  
> 用途：按本说明制作并交付资源；甲方拿到后即可接入产品，**无需你了解甲方代码或技术方案**。  
> 更新：2026-10-19

---

## 你要做什么

按甲方给定的人物清单，做出可直接使用的 **3D 虚拟人模型（GLB）**，并附上简单说明表。  
制作工具优先使用 **[Avaturn](https://avaturn.me)**（在网站里捏人并导出即可）。

---

## 交付物清单（每个形象一份）

| 序号 | 交付物 | 是否必须 | 说明 |
|---|---|---|---|
| 1 | `.glb` 模型文件 | **必须** | 一个形象一个文件 |
| 2 | 填写完整的「交付信息表」（见文末） | **必须** | Excel / 飞书表格 / Markdown 均可 |
| 3 | 正面半身预览图（PNG 或 JPG） | **建议** | 方便甲方核对外观，非技术接入必需 |
| 4 | 授权说明（一句话即可） | **必须** | 写明甲方是否可用于内部演示 / 对外发布；若含商用限制请写清楚 |

**不需要交付：** 源工程工程文件、动作动画、贴图散文件、代码、文档技术方案、音频、人设文案（除非甲方单独约）。

---

## 导出硬性要求（不满足则退回重做）

请在 Avaturn（或同等工具）导出时严格满足：

1. **格式：GLB**（不要只交 FBX / OBJ / VRM，除非甲方书面另行要求）。
2. **必须勾选 / 启用 ARKit 面部表情（ARKit Blendshapes）**  
   - 这是口型、微笑能工作的前提。  
   - 漏勾 = **不合格**，需重新导出。
3. **骨骼需兼容常见人体动画（Mixamo 一类）**  
   - Avaturn 默认导出一般可用；若你用其他工具自建，须保证有标准人体骨架，且头部可被识别。
4. **竖屏半身构图友好**  
   - 人物默认站姿自然、面向镜头；头到腰区域清晰可见。  
   - 双手不要紧贴身体到几乎看不见；手臂不要异常拉长或穿模。
5. **体量控制（手机上要能流畅跑）**  
   - 面数：大约 **3 万三角形** 量级（明显超过请先征得甲方同意）。  
   - 贴图边长：建议 **不超过 1024～2048**。  
   - 不要依赖实时阴影、超多透明层、过重的毛发系统。

---

## 外观与内容要求

甲方会按人物清单提供：人数、气质描述、男女、年龄感、服装风格等。制作时请遵守：

- **严格按甲方清单的气质与性别制作**，不要擅自换风格（例如清单要「温和青年女性」却做成卡通儿童）。
- 东亚面孔优先（若甲方清单未写死种族，默认按甲方口头/表格说明）。
- 半写实即可，不要恐怖谷夸张、也不要纯 Q 版（除非清单明确要求）。
- 服装与发型简洁干净，避免大面积闪烁材质、过亮金属、强噪点贴图。
- **不要**在模型里嵌入水印网格、第三方 Logo、裸露或不当内容。

---

## 文件命名（请按此命名，方便甲方直接使用）

甲方若已给出文件名，**以甲方表格为准**。未另行指定时，使用：

```text
avatar-<编号或英文短名>.glb
```

示例：

```text
avatar-default.glb
avatar-cute-girl.glb
avatar-cute-boy.glb
avatar-young-woman.glb
avatar-young-man.glb
```

对应预览图建议同名：

```text
avatar-cute-girl-preview.png
```

同一批交付放在一个文件夹里，例如：`avatars-delivery-YYYYMMDD/`。

## 自检清单（交之前请全部勾完）

制作方自行确认后再发包：

- [ ] 每个形象都有独立 `.glb`
- [ ] 导出时已开启 **ARKit Blendshapes**
- [ ] 在 Avaturn / 预览器里能正常显示，无黑模、无爆炸网格
- [ ] 站姿面向镜头，半身看起来正常
- [ ] 嘴部闭合自然；微笑不太僵（有表情通道即可，精确口型由甲方侧驱动）
- [ ] 面数与贴图未明显超标
- [ ] 交付信息表已填：中文名、气质一句话、男/女、对应文件名
- [ ] 已写清授权范围
- [ ] 无水印、无不当内容

甲方抽检时可能用预览工具打开 GLB，并检查是否含面部表情通道；不合格项会要求免费返工（以双方合同约定为准）。

## 沟通与改稿

- 需求变更（换服装、换年龄感、增减人数）由甲方书面确认后再改。
- 因未勾 ARKit、格式错误、超面数、穿模明显导致的返工，按不合格退回。
- 主观审美类修改：请先出预览图或 Avaturn 分享链接给甲方确认，再最终导出 GLB，减少无效返工。

---

## 你不需要知道的事

以下由甲方自行处理，**请勿写入交付包，也无需询问技术细节**：

- App / 网页如何加载模型  
- 口型、动画、语音如何驱动  
- 工程目录、脚本、版本管理  

你只负责：**按清单做好合规 GLB + 信息表 +（建议）预览图**。
