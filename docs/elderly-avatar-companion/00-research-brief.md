# 研究简报（Phase 0–2）：中国大陆老年人虚拟形象陪伴产品可行性

- 创建日期：2026-10-09
- 模式：deep-research **Deep + open-consulting**；delivery_medium = file；persistence_rule = audit_bundle_only
- complexity_score：9/10（子问题多 2、来源类型多 2、法规/价格时效性 2、伦理争议 1、交付严谨度 2）

## 研究问题

评估一款面向中国大陆独居/空巢、认知和听说基本正常、不擅长复杂 App 操作的老人的"虚拟形象 + 可打断自然语音对话"陪伴产品（运行于现有平板/智能屏），是否值得开发；若值得，首版做什么、如何验证、何时停止。

## 范围

- 地域：中国大陆；数据优先 2020 年后（七普为人口基准）。
- 包含：用户需求、替代方案、竞品、产品形态、技术链路、商业模式、成本、运营、隐私/安全/法规、验证计划。
- 不包含：专用硬件研发、医疗诊断/健康监测、法律意见。

## 工作假设（待验证，非结论）

- H1 目标老人中存在一个"愿意每周多次与虚拟形象对话"的细分群体。
- H2 子女愿意为父母购买或协助设置，但老人的持续使用不由子女意愿决定。
- H3 现有中端安卓平板 + 云端语音/大模型可实现可接受的打断体验，无需专用硬件。
- H4 普通话 ASR 对老年口音的错误率显著高于标准测试集，方言是体验瓶颈之一。
- H5 产品需履行生成式 AI 服务相关备案/安全评估义务（适用性待法律专业人士判断）。
