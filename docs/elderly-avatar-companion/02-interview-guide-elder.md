# 老人半结构访谈提纲（30–45 分钟，单人，探索性）

> **使用边界**：这是一次探索性访谈，用来找线索、改问题、修正假设。**单次访谈不能代表目标人群**：一个人的居住状态、健康、性格、家庭关系、城乡和方言背景都只是一个样本点，无法估计比例，也无法判断"多数老人是否愿意使用"。访谈结果只能写成"该受访者说/做了……"，不能写成"老人需要……"。

## 0. 访谈前准备（不计时）

- 知情同意：说明目的（"了解老人平时怎么过日子、怎么用电子设备"，**不要**说"我们在做陪伴孤独老人的产品"）、时长、可随时停止、可拒答、是否录音（单独征得同意；不同意就只做笔记）、记录如何保存和删除。
- 访谈地点尽量在受访者家里，便于观察设备摆放、电视位置、噪声和光线。
- 访谈者不要是受访者的子女；若子女在场，请其先回避或坐在旁边不插话，并在笔记中注明"子女在场"。
- 准备材料：笔记纸、计时器；概念测试用的 1 张静态示意图（虚拟形象 + 大按钮），或一个可点击原型。**不要**带产品宣传话术。
- 记录原则：区分"原话""观察到的行为""访谈者解读"。

## 1. 开场与基本情况（5 分钟）

1. 您现在平时住在这里，家里还有谁一起住吗？（只记录事实，不追问原因）
2. 您一天大概是怎么过的？从早上起来说起就行。
3. 最近一周，有没有哪天跟平时不太一样？那天发生了什么？

> 避免："您一个人住会不会孤单？"——这类问题预设了答案。

## 2. 真实经历：和人说话与打发时间（10 分钟）

4. 上一次跟人聊得比较久，是什么时候？跟谁？聊了什么？是怎么开始聊的？
5. 平时谁会给您打电话或者视频？一般谁先打？多久一次？通常聊多久？
6. 有没有想找人说说话但没找到的时候？当时您做了什么？（若受访者说"没有"，接受，不追问"真的没有吗"）
7. 家里电视、收音机、手机，平时哪个开得最多？什么时候开？开着的时候您在做什么？
8. 小区或附近有没有您会去的地方或活动？最近一次是什么时候去的？什么情况下就不去了？

## 3. 设备与技术使用（8 分钟）

9. 您现在用的手机是谁帮您买的、谁帮您设置的？平时用它做哪几件事？请您演示一下平时怎么打视频（观察，不帮忙）。
10. 有没有哪个功能是您想用、但不会用或不敢用的？最近一次卡住是什么情况？后来怎么解决的？
11. 您用过或见过能"说话问它"的东西吗？比如音箱、手机语音、电视遥控器语音。（若用过）上一次用是做什么？好用吗？后来还用吗？为什么？
12. 有没有遇到过电话或手机上有人骗钱、推销？您现在怎么判断真假？

## 4. 隐私与信任（5 分钟）

13. 家里的东西，有什么是您不希望别人（包括子女）知道或看到的？
14. 如果有个设备能记住您说过的话，您觉得它记住什么可以，什么不行？谁能看？（先开放回答，再追问"称呼、爱好、身体情况、家里的事"各自怎么看）

## 5. 概念测试（10 分钟，最后进行）

> 先中性描述，再给示意图。说明"这只是个想法，还没做好，说不好也没关系，我们不是这个东西的设计者"（降低讨好偏差）。

15. 中性描述："有一种放在家里的平板，屏幕上有一个人的形象。您按一下大按钮或者叫它一声，就可以跟它说话，它会回答，您也可以随时打断它。它平时不听家里的声音。"
    - 您听完第一反应是什么？
    - 您觉得这个东西是给谁用的？
16. 展示示意图（若有多版形象/声音，顺序随机）：
    - 这个人看起来像什么样的人？说话您愿意听吗？哪里让您不舒服？
    - 您希望它怎么称呼您？它说话应该快一点还是慢一点？
17. 想象它已经放在您家里了：您会在什么时候按它？会跟它说什么？什么情况下您就不会再用了？
18. 如果是子女买来放在您家，您会怎么想？如果要您自己每月出钱，您会怎么想？（只记录反应，不报价、不讨价还价；**不**把回答当成付费意愿证据）
19. 有没有什么事，您觉得这种东西绝对不应该做？

## 6. 收尾（2 分钟）

20. 今天聊的里面，有没有您觉得我没问到、但很重要的事？
21. 以后如果有能试用的样品，您愿意试吗？可以联系谁？（单独记录，不影响前面回答）

## 访谈后记录模板

| 项 | 内容 |
|---|---|
| 基本情况 | 年龄段、居住状态、城乡、方言/口音、听力/视力自述、子女距离（仅事实） |
| 现有替代方式与频率 | 原话 + 行为 |
| 技术能力观察 | 演示中卡住的步骤 |
| 对概念的反应 | 原话；区分自发提到 vs 被提示后才说 |
| 拒绝/担忧信号 | 原话 |
| 意外发现 | 推翻或修正了哪条假设（H1–H5） |
| 访谈者偏差自查 | 是否有引导、子女在场、讨好迹象 |

## 常见诱导式问法 → 替代问法

| 避免 | 改为 |
|---|---|
| 您会不会觉得孤单？ | 上一次跟人聊得比较久是什么时候？ |
| 如果有个 AI 陪您聊天，您会用吗？ | （先问现有做法，最后中性描述概念）您第一反应是什么？ |
| 您愿意每月花 30 块钱吗？ | 如果要您自己出钱，您会怎么想？（只记录反应） |
| 这个形象是不是很亲切？ | 这个人看起来像什么样的人？哪里让您不舒服？ |
| 子女是不是很忙没空陪您？ | 平时谁会给您打电话？一般谁先打？ |
