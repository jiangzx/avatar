# 结束对话与重开体验设计

日期：2026-10-31
状态：已批准。用户 2026-10-31 在 `/grill-me` 中「全部接受建议」。
范围：Flutter 客户端（`app/lib`）；不改 gateway / protocol。

## 1. 问题

- 红色挂断键单击即结束，没有确认；对长者用户误触概率高。
- 结束后顶部只显示「对话已结束」，页面没有重开入口；`SessionStartGuard` 永久关闭，`_retry` 和 `_startNativeSession` 都拒绝，设置页选回同一角色也不会重建页面。只能退出 App 再进。
- 结束会发送 `session.end`，网关立即销毁会话并异步抽取记忆；重开必然是新的会话（一个主人同时只有一个活跃会话），会重新开场，记忆告知不会重复，快照会带上一会话未抽取的尾部。

## 2. 目标用户与场景

- 主要用户是长者：大字（≥18sp）、大触控（≥60dp）、明确文案、避免死路。
- 场景：聊完主动结束；或误触后想立刻继续；或结束后想换一位伙伴。

## 3. 已定决策

| # | 决策 | 说明 |
|---|---|---|
| D1 | 红键语义 = 「结束这次聊天」 | 不改成「停止当前回答」；打断回答仍靠说话。 |
| D2 | 二次确认，安全默认 | 大按钮框；「继续聊天」是填充主按钮，「结束聊天」是红色文字；点框外/返回键 = 继续。 |
| D3 | 结束后显示大卡片 | 保留头像，中央卡片「这次聊天结束了 / 想聊的时候，随时接着聊。」；主按钮「接着聊天」，次按钮「换个伙伴」；隐藏静音/结束按钮，清空字幕和顶部「对话已结束」小字。 |
| D4 | 「接着聊天」= 页内新会话 | 复用当前头像引擎；不重载 WebView/Duix，不重问权限；网关/协议不改。 |
| D5 | 页内重开而非整页重建 | `SessionStartGuard` 增加可复位；旧音频完全 stop 后再开新音频；重开失败走现有「错误 + 重试」。 |
| D6 | 底部圆钮保持图标 | 64dp 圆钮只放图标，不加可见文字；「静音 / 取消静音」「结束聊天」放在语义标签里。2026-10-31 真机反馈：圆内文字拥挤，去掉可见文字。 |

## 4. 交互细节

### 4.1 结束确认

- 标题 24sp：「要结束这次聊天吗？」
- 正文 20sp：「结束以后，想聊随时可以接着聊。」
- 主按钮 60dp 高、20sp：「继续聊天」（FilledButton，安全默认）。
- 次按钮 60dp 高、20sp：「结束聊天」（TextButton，`colorScheme.error`）。
- 点框外、按返回键都返回「继续」，不得结束。
- 确认框打开时会话继续运行；取消后无缝继续。
- 现有 `confirmLarge` 的 `?? false` 语义不能反用；为结束场景单独实现 `confirmEndChat`。

### 4.2 结束态

- 结束确认后立即进入结束态：隐藏底部静音/结束按钮与字幕卡片；顶部状态小字不显示。
- 中央大卡片（`Key('ended-card')`）：黑色 87% 背景、12 圆角、24 边距、标题 26sp、正文 18sp。
- 主按钮 `Key('restart')`：「接着聊天」，64dp 高、22sp。
- 次按钮 `Key('change-partner')`：「换个伙伴」，60dp 高、20sp；打开现有设置页。
- 结束态头像继续显示；屏幕常亮关闭（`setWakelock(false)`），重开时恢复。
- 结束后到达的会话事件仍转发给引擎，但不再更新字幕/状态等 UI。

### 4.3 重开

- `_restart` 先等待 `_ending`（旧会话 stop）和 `_startDone`（可能在途的启动）完成，再 `SessionStartGuard.reset()`。
- 设置 `_ended = false`，状态「连接中…」，清空字幕，恢复屏幕常亮，调用 `_startNativeSession`。
- 旧音频 stop 后才开新音频，避免麦克风冲突。
- 重开失败时显示现有错误卡片和「重试」，不得回到结束态死路。
- `SessionStartGuard.reset()` 使旧 token 失效并允许新的 begin。

### 4.4 按钮

- 静音键：只显示 mic / mic_off 图标；语义标签为「静音 / 取消静音」。
- 结束键：`Colors.redAccent` 圆钮 + call_end 图标；语义标签「结束聊天」。
- 圆钮保持 64dp 触控区，不显示可见文字；2026-10-31 真机反馈圆内文字拥挤，已按此调整。
- 文字放在 64dp 圆钮内，图标 26、文字 18sp、单行、FittedBox 防大字号溢出。

## 5. 非目标

- 不做 60 秒内 resume 原会话；不做通话摘要、时长或文字记录。
- 不改网关、协议、记忆抽取和开场逻辑。
- 不新增结束后的「退出 App」按钮。
- 不重做底部设置按钮的视觉。

## 6. 风险与验证

- **麦克风重入**：页内重开的主要风险。需真机连续执行「结束 → 接着聊天」至少 3 次，确认麦克风、播放器、垫话都正常。
- **守卫竞态**：结束发生在启动途中时，旧启动必须被作废；`_restart` 必须等旧 stop 完成。
- **确认框误关**：点框外/返回必须是「继续」，不得因 `?? false` 反用而结束。
- **对比度**：结束键为红底白色图标，图标对比度 ≥3:1；确认框破坏项用主题 error 色。
- **真机不可用**：若本次无法真机验证，记录到 `docs/blockers.md`，不得声称已真机通过。

## 7. 验收

- `flutter test` 全量通过；新增守卫、确认框、结束态、页内重开测试。
- `flutter analyze` 通过。
- 手工/真机：结束确认可取消；结束后可一键重开；重开失败有重试；静音/结束按钮无可见文字、图标语义清晰。
- 真机（2026-10-31，小米 22101317C / Android 13）：连续 3 次「结束 → 接着聊天」通过；4 次 `session_ready`（首启 + 3 次重开），无 fail/error/timeout/closed 诊断；结束后麦克风指示消失、重开后恢复；每次重开有 `duix_playback_start/end` 且 `lips=true`。主观听音待用户确认。
